# Опыт в АО Казактелекоме как SQL Разработчик

В ходе практики в АО «Казахтелеком» я работал с клиентской базой данных. Я выполнял задачи такими как:
- Находить ошибочно заполненные данные пользователей в базе и исправить их.
- Объединять несколько таблиц и составлять сложные SQL-запросы.
- Найти клиентов в определенных регионах и формировать полную информацию о них, объединяя все клиентские таблицы.
- Оптимизировать запросы для ускорения поиска данных при работе с несколькими таблицами.

Помимо опыта, полученного в АО «Казахтелеком», в этом репозитории также представлены дополнительные задачи, которые я выполнял параллельно, чтобы применять и укреплять свои практические знания.
